## 2. Non-Negotiable Bug Fixes & Invariants (Do Not Regress)

Every item below corresponds to a real bug fixed during Quest bring-up or Horizon Store submission. Do not remove or refactor away these guards without reproducing and re-verifying on physical Quest hardware.

### 2.1 `UnityPlayerGameActivity` Launch Crash (`VRC.Quest.Functional.1`)
- Meta XR Core SDK requires `PlayerSettings.Android.applicationEntry = AndroidApplicationEntry.GameActivity` (`com.unity3d.player.UnityPlayerGameActivity`) on Unity 6.
- `UnityPlayerGameActivity` extends `AppCompatActivity` and throws `IllegalStateException` on frame 0 unless its `<activity>` theme inherits `Theme.AppCompat`.
- **SDK Gotcha**: `Packages/com.meta.xr.sdk.core/Editor/OVRManifestPreprocessor.cs` only rewrites `@android:style/Theme.Black.NoTitleBar.Fullscreen` and leaves Unity 6's `@style/UnityThemeSelector` untouched.
- **Invariant**: Keep `android:theme="@style/BaseUnityGameActivityTheme"` plus `<meta-data android:name="unityplayer.UnityActivity" android:value="true" />` and `<meta-data android:name="android.app.lib_name" android:value="game" />` inside `<activity>` in `Assets/Plugins/Android/AndroidManifest.xml`, enforced automatically during builds by `SonicQuestBuildTools.EnsureGameActivityThemeAndMetaData`.

### 2.2 Quest Virtual Keyboard Preview Textbox Sync / Focus Loss / Jump on Close
- **`GameActivity` `gti.InputConnection` Bug & Native `EditText` Bridge**: Unity 6's `UnityPlayerGameActivity` (`androidx.games:games-activity:4.4.0`) routes `TouchScreenKeyboard` through `com.google.androidgamesdk.gametextinput.InputConnection` (`gti.InputConnection`), whose `getExtractedText(...)` returns `null` and whose `commitText` / `setComposingText` / `deleteSurroundingText` never call `InputMethodManager.updateExtractedText(...)` or `updateSelection(...)` (only initial `setState` and `onKey(KEYCODE_DEL)` Backspace notify IMM). As a result, Horizon OS's virtual keyboard preview textbox freezes on initial text during forward typing and stays blank for empty web inputs.
- **Invariant**: On `#if UNITY_ANDROID && !UNITY_EDITOR`, ALL text inputs (`SearchBar`, `BrowserUrlBar`, and GeckoView in-page web inputs in `SonicWebBrowserManager`) bypass Unity's `TouchScreenKeyboard` and route through `Assets/SonicTopography/Plugins/Android/SonicQuestSoftInputBridge.java` + `Assets/SonicTopography/Scripts/SonicQuestNativeKeyboard.cs` (a hidden `1x1`-style off-visual `EditText` attached to `android.R.id.content` whose standard `EditableInputConnection` implements `getExtractedText`, `updateExtractedText`, `updateSelection`, `setInitialSurroundingText`, and clears `IME_FLAG_NO_EXTRACT_UI`). `SonicQuestVirtualKeyboardOpener` disables UGUI `InputField` interaction on Android (`transition = Selectable.Transition.None`, `enabled = false`) while keeping programmatic text/caret/placeholder rendering synced, and `SonicQuestSoftInputBridge.close` resolves `targetSid` synchronously + retries `showSoftInput` if a back-to-back tab switch clobbers the overlay asynchronously. Keep `<uses-feature android:name="oculus.software.overlay_keyboard" android:required="false" />`.
- **Focus-Loss Trap**: Opening the Horizon OS virtual keyboard takes Android window focus (`OnApplicationFocus(false)`). `SonicTopographyVRBootstrap.OnApplicationFocus` must check `SonicQuestVirtualKeyboardOpener.IsKeyboardActiveOrRecentlyUsed(1.0f)` (which checks `SonicQuestNativeKeyboard.IsActive` as well) and call `ResetPinchAndSelectionStatesOnly()` instead of `ResetAllInteractionAndUIStates()` — toggling `XRUIInputModule` or clearing focus prematurely kills the OS keyboard session.
- **Phantom Jump Guard**: Controller Button A / focus handoff during keyboard open/close triggers spurious Button A presses. Keep `AudioFloorControllerActions.CancelAnyActiveJumpImmediate(...)` and the `_suppressJumpUntilTime` (~1.0s) guard intact around keyboard/focus transitions.

### 2.3 Touch Plus Controller Orientation, Scale Lock, Ray Trim & Modality Hiding
- Implemented in `Assets/SonicTopography/Scripts/SonicMetaQuestController.cs` using official assets under `Assets/SonicTopography/Resources/Controllers/`.
- **Orientation**: When `OVRInput.GetLocalControllerPosition/Rotation` is unavailable, OpenXR Grip Pose must be converted to the Touch Plus FBX/VRAPI pose using `GripToVrapiOffsetInverse = Matrix4x4.TRS(new Vector3(0f, -0.03f, -0.04f), new Quaternion(-0.5f, 0f, 0f, 0.86603f), Vector3.one).inverse`.
- **Scale Calibration**: Measure `meshRenderer.bounds.size` **once** after 2 tracked frames at temporary `Quaternion.identity` rotation (`CalibrateAndLockScaleOnce`, target `0.108f` meters max unrotated dimension) and lock `_lockedLocalScale`. Measuring rotated AABB bounds causes scale drift as the wrist turns.
- **Mesh Filtering**: Disable and exclude any child `SkinnedMeshRenderer` whose name contains `"battery"` (`FindMainControllerMeshRenderer`). Disable XRI's generic `UniversalController` renderers (`HideGenericControllerRenderers`).
- **Ray Nozzle Trim**: Keep `OffsetXriRayOriginForward()` and `[BeforeRenderOrder(500)] OnBeforeRenderTrimPointerLine()` trimming `0.078m` (`RayNozzleStartOffsetMeters`) so pointer lines start cleanly at the controller tip without z-fighting/flashing on the mesh.
- **Modality Hiding**: Hide controller `modelRoot` whenever bare hand tracking is active (`IsHandTrackingActive()`).

### 2.4 Hand Tracking vs. Controller Input, Teleport Layer & Vertical Ground Lock
- Implemented in `SonicTopographyVRBootstrap.cs` and `AudioFloorControllerActions.cs`:
  - `GlassStageCube` `TeleportationArea` must stay strictly on the `"Teleport"` interaction layer (`bit 31`), while `NearFarInteractor`, `XRPokeInteractor`, and `CurveInteractionCaster` must exclude `bit 31` so hands never hover/teleport unintentionally on the glass floor.
  - Keep `ClimbProvider` and `ClimbTeleportInteractor` disabled so hand pinches never trigger climbing.
  - Button A (Jump) and Button X (Next Track) must explicitly ignore bare hand tracking (`isBareHandActive`, `_isRightDeviceHandTracking`, `_isLeftDeviceHandTracking`).
  - Keep `GravityProvider.useGravity = false` and let `AudioFloorControllerActions.LockVerticalOriginToGround()` snap `XROrigin` vertically (`Glass Stage Y = 0`, `Terrain Platter Y = -11.0`, abyss respawn `< -22f`), forcing `CameraYOffset = 0` on Android so height never jitters or drifts.

### 2.5 Rendering, 1.5x Supersampling & Custom Shaders
- `SonicTopographyVRBootstrap.ConfigureXRPerformanceAndResolution()` locks `Application.targetFrameRate = 72`, `QualitySettings.vSyncCount = 0`, `XRSettings.eyeTextureResolutionScale = 1.5f`, `UniversalRenderPipelineAsset.renderScale = 1.5f`, `supportsHDR = false`, `supportsCameraOpaqueTexture = false`, `supportsCameraDepthTexture = false`, no shadows, no post-processing, and pure `#000000` OLED sky/camera clear.
- `SonicTopographyVisualizer` splits terrain pillars into 16-bit index chunks (`PILLARS_PER_CHUNK = 3000`) for Quest 3 Adreno GPU compatibility.
- Do **not** alter custom shaders in `Assets/SonicTopography/Resources/Shaders/` (`SonicGlassStage.shader`, `SonicTerrainPillars.shader`, `SonicStarRiver.shader`, `SonicVisionGlassUI.shader`, etc.) unless a task explicitly requires visual changes.

### 2.6 Audio Pipeline, Permissions & Meta Horizon Store Workflow
- **Prohibited / Unused Features**: Strip `com.oculus.permission.EYE_TRACKING` and `oculus.software.eye_tracking` in `AndroidManifest.xml` (`tools:node="remove"`) and `SonicQuestBuildTools.OnPostGenerateGradleAndroidProject`. Target strictly `quest3|quest3s` (`com.oculus.supportedDevices`). Filter `armeabi-v7a` from `launcher/build.gradle` `ignoreAssetsPattern` so builds stay pure 64-bit `arm64-v8a`.
- **Audio Permissions**: Keep `READ_MEDIA_AUDIO` and `READ_EXTERNAL_STORAGE` declared in `AndroidManifest.xml` (both are registered and justified on Meta Store Dashboard). At runtime on Android 13+/Horizon OS (`SDK_INT >= 33`), `SonicMusicLibraryManager.RequestAndroidAudioPermissionsIfNeeded()` only requests `READ_MEDIA_AUDIO`. Denying permissions must remain non-blocking and crash-free (`VRC.Quest.Security.2` — falls back to `"No Songs Found"` UI).
- **Audio Decoding**: Non-FMOD containers (`.flac`, `.m4a`, `.aac`, `.mp4`, `.opus`) decode off the main thread via `Assets/SonicTopography/Plugins/Android/SonicAndroidAudioDecoder.java` (`MediaExtractor` + `MediaCodec`) into stereo 16-bit WAVs under `Application.temporaryCachePath/SonicAudioCache`. `SonicTopographyAudioEngine.GetAudioData()` reads live FFT output via `AudioSource.GetSpectrumData`.
- **Mandatory Pre-Upload Device Test Rule**: Never upload a Store build based solely on static checks (`aapt` / `apksigner`) or an older build already sitting on the headset. Before every Store upload:
  1. Increment `PlayerSettings.Android.bundleVersionCode` (Meta rejects duplicate version codes).
  2. Clean-build via `AudioFloor/Build Quest 3 APK` (`SonicQuestBuildTools.BuildQuest3Apk`).
  3. Uninstall `com.Dexter.AudioFloor` from Quest and clean-install `Builds/AudioFloor.apk`.
  4. Verify cold launch, `metavr adb logcat --buffer crash`, `VrApi` FPS, and both granted and denied permission states on headset before running `metavr store dist upload --app-id 1822201432331484 --channel LIVE --apk "D:\Unity Project\AudioFloor\Builds\AudioFloor.apk"`.

### 2.7 Built-in Browser (Mozilla GeckoView + `OVROverlay` Underlay + WebExtension FFT)
- **Gradle & Manifest Stripping**: `SonicQuestBuildTools.OnPostGenerateGradleAndroidProject` injects `https://maven.mozilla.org/maven2/` into `settings.gradle` and `org.mozilla.geckoview:geckoview-arm64-v8a:133.0.20241209150345` into `unityLibrary/build.gradle`. Both `Assets/Plugins/Android/AndroidManifest.xml` and `launcher/src/main/AndroidManifest.xml` strip `RECORD_AUDIO`, `CAMERA`, `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION`, `MODIFY_AUDIO_SETTINGS`, and `HIGH_SAMPLING_RATE_SENSORS` (`tools:node="remove"`) so GeckoView does not pull unnecessary runtime/review-required permissions, while preserving `INTERNET`, `ACCESS_NETWORK_STATE`, and `WAKE_LOCK` (`org.mozilla.gecko.GeckoAppShell.setWakeLockState` acquires audio/video wake locks without catching `SecurityException`). (`RemoveManifestEntry` must preserve nodes with `tools:node="remove"`.)
- **Compositor Rendering**: `SonicWebBrowserManager.cs` initializes lazily on first Browser tab open, ensures `OVRManager` (leaving `trackingOriginType` untouched at default — on SDK v207 + OpenXR >= 1.11, setting `OVRManager.trackingOriginType = Stage` calls `OpenXRSettings.RefreshRecenterSpace()` and shifts `XROrigin` away from `(0,0,0)`; `AudioFloorControllerActions.GetPlayerFeetWorldPos` also evaluates stage/terrain bounds at HMD world XZ rather than `_originTransform.position`), disables dynres/passthrough, re-locks `1.5x` URP render scale, creates an `OVROverlay` (`Underlay`, `Quad`, `isExternalSurface = true`, `1280x752` matching the edge-to-edge `960x564`, `r=38px` `BrowserViewport` inside `CentralGlassWindow` with a `0.5px`-per-side overlay quad inset so the quad ends cleanly under the `1px` glass border, while `BottomBrowserNavBar` swaps into `BottomPlayerBar` on the Browser tab with minimal `Back`, `Forward`, `Reload`, `BrowserUrlBar` + inline `BrowserUrlGoBtn`, and `BrowserDefaultBtn` persisted via `PlayerPrefs` `SonicTopography_BrowserDefaultUrl`), and passes `overlay.externalSurfaceObject` (`IntPtr` JNI `Surface`) via `AndroidJNI.CallVoidMethod` to `Assets/SonicTopography/Plugins/Android/SonicGeckoBrowserBridge.java`. `SonicBrowserUnderlayPunchout.shader` (`Blend Zero SrcAlpha, One Zero`, `ColorMask RGBA`, `_BorderInset = 1.0`) uses `SonicGlassSurface` `UV1`/`UV2`/`UV3` SDF parameters on `BrowserPunchout` to clear eye-buffer RGB+A to `(0,0,0,0)` strictly inside the `r=38px` rounded interior while preserving `CentralGlassWindow`'s crisp `1px` border stroke and locking outer-corner alpha to `1.0` (`_browserPunchoutRawImage` MUST use `Color.white` and `canvasRenderer.cullTransparentMesh = false` so `CanvasRenderer` never culls the punchout quad before the shader runs), while UI fade-in/surface binding gates both punchout and overlay visibility (`canvasAlpha > 0.85f`). Keep `session.setActive(true)` when hiding the panel so background browser audio continues.
- **Audio FFT & WebExtension Bridge**: Built-in WebExtension `Assets/StreamingAssets/sonic_browser_ext/` (`manifest.json` MUST include `"geckoViewAddons"`, `"nativeMessaging"`, `"nativeMessagingFromContent"`) runs `AudioContext.createMediaElementSource` -> raw unsmoothed `AnalyserNode(fftSize=1024, minDecibels=-85, maxDecibels=-10, smoothingTimeConstant=0.0)` -> `audioCtx.destination` at `12ms` interval (+ `30ms`/`45ms` `setInterval` fallback when `rAF` is throttled) and sends Base64 512-byte FFT spectra + `mediaSession` metadata/artwork over `connectNative("sonic_browser")` to `SonicGeckoBrowserBridge` (`WebExtension.MessageDelegate.onConnect` returns `void` and binds `port.setDelegate`), polled by `SonicWebBrowserManager` into `SonicTopographyAudioEngine.SetExternalAudioSpectrum(...)` where `EXT_BYTE_TO_DB`/`EXT_BYTE_TO_LINEAR` LUTs + adaptive peak-dB loudness matching (`-14 dB` ceiling) feed Unity's single-pass temporal smoother identically to local PCM audio. `SonicWebBrowserManager` also downloads current browser artwork (`UnityWebRequestTexture.GetTexture(..., nonReadable=false)`) and updates `SonicTopographyVisualizer.SetAlbumArtPalette(...)` (and clears any prior paused local song palette on Browser switch via `ApplyBrowserThemeToVisualizer`, while `SonicMusicPlayerController.TogglePlayPause` restores local album art when resuming local tracks). Local `SonicMusicPlayerController` and `SonicWebBrowserManager` mutually pause on playback start, local song-card equalizer badges/bars stay hidden whenever browser audio is active (`isBrowserPlaying`), and `AudioFloorControllerActions` routes controller B/X/Y buttons to `_browserManager` when `IsBrowserAudioActive` and local audio isn't playing.
- **Virtual Keyboard & Input**: In-page inputs & URL bar integrate with `SonicQuestNativeKeyboard` / `SonicQuestVirtualKeyboardOpener` (`SetExternalKeyboardActive` + `MarkKeyboardActivity`) and `AudioFloorControllerActions.CancelAnyActiveJumpImmediate(...)` so opening/closing the OS keyboard preserves all §2.2 guards. On Android device builds, `SonicWebBrowserManager.OpenWebVirtualKeyboard` / `PollWebVirtualKeyboard` and `SonicQuestVirtualKeyboardOpener` use `SonicQuestSoftInputBridge` (never `GameActivity`'s `TouchScreenKeyboard`). For in-page GeckoView inputs, `SonicGeckoBrowserBridge.sendTextToPage` immediately updates `mSoftInputInitialText`, `SonicGeckoBrowserBridge.showSoftInput` requests `requestActiveValue`, and `content.js` listens to `focusin`, `click` (already-focused re-tap), `focusout`, and page `input`/`change` (`inputSync`, suppressed during native commits) so reopening the keyboard preserves existing field text via `softInputValSeq` sync (without clobbering active typing via `_webUserHasTypedInSession`). Neither `PollWebVirtualKeyboard()` nor `BrowserUrlBar` ever auto-dispatches `Enter` when Horizon OS sends `IME_ACTION_DONE` (`action=6`) on the keyboard X dismiss button (`BrowserUrlGoBtn` handles URL submission). Both LeftHand and RightHand `UI Scroll` bindings in `XRI Default Input Actions.inputactions` must keep `"processors": "StickDeadzone(min=0.25,max=0.925)"` (plus `0.75f` delta filtering and `0.35f` scaling in `SonicBrowserViewportInput.OnScroll`), and `SonicTopographyVRBootstrap.EnsureXRInputReady` keeps `xrInputModule.enableMouseInput = false` on Android to prevent phantom/drift scrolling in Music and Browser panels.

## 3. Remaining Architectural Watch-Outs (Account for Before New Features)

1. **Tight GPU Budget at 1.5x Render Scale**: `VrApi` telemetry on Quest 3 measured `GPU% ~ 0.87-0.96` (`App ~ 8.7-12.2 ms`) at 72–90 Hz. Keep `OVROverlay` (`Underlay` + `isExternalSurface = true`) for video/browser surfaces rather than copying video frames into Unity `RenderTexture`s. Also test Widevine EME DRM behavior (`drmSilent`) on Quest hardware whenever validating streaming sites.
2. **Synchronous PCM Upload on Track Load**: `SonicMusicLibraryManager.LoadTrackClipCoroutine` sets `dh.streamAudio = false` (full synchronous PCM buffer upload on completion). Switching `streamAudio` requires verifying `AudioSource.time` seeking and `clip.length` accuracy across formats on Quest. *(Duplicate UI rebuilds and hidden-tab `RefreshBrowseList` disk scans on track load, 512 MB LRU eviction in `SonicAudioCache`, `OVRInput` per-controller animator axis calls, and `#if UNITY_EDITOR || UNITY_STANDALONE` gating of `Keyboard.current` WASD/shortcuts have been resolved.)*
